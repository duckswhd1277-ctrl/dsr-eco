발견된 버그 및 개선사항:

1. 🐛 [버그] 문서 클릭 기능 미구현
   - downloadDocument() 함수가 정의되지 않음
   - 문서를 클릭해도 아무 동작 안 함

2. 🐛 [버그] 항목 삭제 기능 부재
   - 할일 항목 삭제 불가
   - 오류 항목 수정 불가

3. 🐛 [버그] 모바일 반응형 불완전
   - 3열 그리드가 모바일에서 1열로 축소 안 됨
   - 태블릿 크기에서 2열로 적응 안 함

4. ⚠️ [개선] 캘린더 이벤트 표시 overflow
   - 셀 높이 고정(60px)으로 이벤트 많으면 겹침
   - 동적 높이 조정 필요

5. ⚠️ [개선] 중복 항목 추가 가능
   - 같은 이름의 항목 여러 번 추가 가능
   - 중복 방지 로직 추가 필요

6. ⚠️ [개선] 항목 수정 기능 부재
   - 생성된 항목 수정 불가
   - 수정 모달 기능 필요

7. ⚠️ [개선] 제출 기한 경고 기능 없음
   - 기한이 임박해도 시각적 경고 없음
   - D-7, D-3 등 경고 시스템 필요

8. ⚠️ [개선] 데이터 유효성 검증 강화
   - 공백 문자열만 입력 가능할 수 있음
   - 더 철저한 검증 필요

9. ⚠️ [개선] 목록 높이 고정
   - 항목 많을 때 스크롤 불편
   - 동적 높이 조정 필요

10. ⚠️ [개선] 접근성(Accessibility) 개선
    - 색상만으로 상태 표현
    - WCAG 기준 미충족 가능
