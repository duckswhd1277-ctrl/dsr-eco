# briefing-improver

**약점 분석 → 이슈 등록 → 작업 → 문서 최적화를 자동으로 순환하는 통합 개선 스킬**

## 개요

프로젝트의 약점을 자동으로 분석하고, 이슈로 등록한 후, 작업을 처리하고, 문서를 최적화하는 **완전 자동화된 개선 사이클 스킬**입니다.

## 🎯 목적

- 🔍 **약점 자동 감지**: 프로젝트의 모든 약점 분석
- 📝 **이슈 자동 등록**: issue-writer로 깃이슈 생성
- ⚙️ **작업 자동 처리**: issue-runner로 이슈 해결
- 📚 **문서 자동 최적화**: doc-optimizer로 문서 정리
- 🔄 **반복 순환**: 약점 없을 때까지 반복

## 🔧 주요 기능

### 1️⃣ 약점 분석 (Briefing Audit)
```
✓ 코드 품질 검토
✓ 문서 일관성 확인
✓ 성능 병목 감지
✓ 보안 취약점 확인
✓ UX/UI 이슈 분석
✓ 구조적 문제 파악
```

### 2️⃣ 이슈 등록 (Issue Registration)
```
✓ issue-writer 스킬 호출
✓ 발견된 약점을 깃이슈로 등록
✓ 우선순위 자동 지정
✓ 카테고리 자동 분류
✓ 상세 설명 자동 생성
```

### 3️⃣ 작업 처리 (Issue Resolution)
```
✓ issue-runner 스킬 호출
✓ 등록된 이슈 자동 처리
✓ 코드 수정/최적화
✓ 버그 수정
✓ 기능 개선
✓ 자동 커밋
✓ Issue closed
```

### 4️⃣ 문서 최적화 (Documentation Optimization)
```
✓ doc-optimizer 스킬 호출
✓ 모든 문서 검사
✓ 링크 유효성 검증
✓ 일관성 확인
✓ 내용 최적화
✓ 메타데이터 관리
```

### 5️⃣ 반복 순환 (Cycle Repetition)
```
✓ 새로운 약점 감지 여부 확인
✓ 발견된 약점 있으면 1번부터 반복
✓ 약점 없으면 완료
```

## 📊 워크플로우

```
briefing-improver 시작
    ↓
[Phase 1] 약점 분석
    ├─ 코드 품질 검토
    ├─ 문서 일관성 확인
    ├─ 성능 분석
    ├─ 보안 확인
    └─ UX/UI 분석
    ↓
[Phase 2] 이슈 등록 (issue-writer)
    ├─ 약점 → 이슈 생성
    ├─ 우선순위 지정
    ├─ 카테고리 분류
    └─ GitHub에 등록
    ↓
[Phase 3] 작업 처리 (issue-runner)
    ├─ 등록된 이슈 확인
    ├─ 코드/문서 수정
    ├─ 자동 커밋
    └─ Issue closed
    ↓
[Phase 4] 문서 최적화 (doc-optimizer)
    ├─ 모든 문서 검사
    ├─ 링크 검증
    ├─ 일관성 확인
    └─ 최적화 완료
    ↓
[Phase 5] 반복 여부 판단
    ├─ 새로운 약점? → YES → Phase 1로 복귀
    └─ 완료 → NO → 종료 ✅
```

## 🎓 핵심 로직

### Cycle 구조
```javascript
briefingImprover() {
  let cycleCount = 0
  
  while (true) {
    cycleCount++
    
    // Phase 1: 약점 분석
    const issues = analyzeWeaknesses()
    if (issues.length === 0) break
    
    // Phase 2: issue-writer 호출
    const issueIds = await issueWriter(issues)
    
    // Phase 3: issue-runner 호출
    await issueRunner(issueIds)
    
    // Phase 4: doc-optimizer 호출
    await docOptimizer()
    
    // Phase 5: 재분석 (반복 조건 확인)
    log(`Cycle ${cycleCount} completed`)
  }
  
  return { cycleCount, totalResolved: ... }
}
```

### 약점 분석 카테고리
```
1. 코드 품질
   - 미사용 함수

2. 문서
   - 빠진 문서
   - 오래된 정보
   - 깨진 링크
   
3. 성능
   - 느린 렌더링
   - 과도한 DOM 접근

4. 보안
   - 입력 검증 미흡
   - XSS 취약점
   - 민감 정보 노출
   
5. UX/UI
   - 접근성 부족
   - 반응형 오류
   - 사용성 문제
   
6. 구조
   - 순환 의존성
   - 과도한 커플링
   - 낮은 응집도
```
