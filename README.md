# 안전/환경/PSM 통합 관리 대시보드

순천 율촌산단 철강선 제조업 **총무관리팀**을 위한 통합 관리 시스템입니다.

## 📋 개요

- **대상**: 총무관리팀 (설비팀 포함)
- **관리 항목**: 안전, 환경, PSM (Process Safety Management)
- **주요 기능**: 월간 진행률 추적, 캘린더 기반 일정 관리, 할일 관리

---

## 🎯 주요 기능

### 1️⃣ 진행률 추적
- **환경 관리** 진행률 시각화
- **안전 관리** 진행률 시각화  
- **PSM 관리** 진행률 시각화
- **전체 진행률** 한눈에 확인

### 2️⃣ 월간 캘린더
- 월별 법적 제출 기한 자동 표시
- 할일 항목을 캘린더에 직접 표시
- 월 이동 (이전/다음 버튼)
- 오늘 날짜 강조 표시

### 3️⃣ 할일 관리
- **카테고리별 필터**: 전체/환경/안전/PSM
- **항목 체크**: 완료/진행중 상태 관리
- **새 항목 추가**: 제목, 분류, 날짜 설정
- **자동 저장**: LocalStorage에 자동 보관

### 4️⃣ 문서 라이브러리
- 법규, 양식, 가이드 등 문서 보관
- 아이콘 구분 (📄📋📖⚖️✅)
- 새 문서 추가 기능

### 5️⃣ 제출 기한 설정
- **환경 관리**: 기한 커스터마이징 (기본값: 매월 말일)
- **안전 관리**: 기한 커스터마이징 (기본값: 매월 15일)
- **PSM 관리**: 기한 커스터마이징 (기본값: 월중순)
- **설정 저장**: 설정 자동 보관

### 6️⃣ 데이터 관리
- **자동 저장**: 모든 데이터는 브라우저 LocalStorage에 저장
- **CSV 내보내기**: 엑셀에서 분석 가능한 형식
- **크로스 브라우저**: Chrome, Edge, Firefox 모두 지원

## 🚀 사용 방법

### 시작하기
1. `안전환경PSM_통합관리_대시보드.html` 파일을 브라우저에서 열기
2. 자동으로 샘플 데이터 로드됨
3. 바로 사용 시작

### 할일 추가
1. ✅ **할일 관리** 섹션의 "➕ 새 항목 추가" 클릭
2. 항목명, 분류(환경/안전/PSM), 날짜 입력
3. 저장 버튼 클릭
4. 캘린더와 진행률에 자동 반영

### 항목 완료
1. 체크박스 클릭
2. 상태가 "완료"로 변경
3. 진행률 자동 업데이트

### 제출 기한 설정
1. ⚙️ **제출 기한 설정** 섹션 하단
2. 각 항목별 기한 입력
3. 💾 **설정 저장** 클릭

### 문서 추가
1. 📚 **문서 라이브러리**의 "➕ 문서 추가" 클릭
2. 문서명과 아이콘 선택
3. 저장

### 데이터 내보내기
1. 📥 **데이터 내보내기** 버튼 클릭
2. CSV 파일 자동 다운로드
3. 엑셀에서 열어서 분석
