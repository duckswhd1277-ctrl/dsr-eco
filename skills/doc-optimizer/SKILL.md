# doc-optimizer

**프로젝트 문서 최적화 및 품질 관리 자동화**

## 개요

프로젝트의 모든 문서를 검사, 분석, 최적화하는 스킬입니다.

## 🎯 목적

- 📚 문서 품질 유지
- 🔗 링크 및 참조 검증
- ✨ 내용 일관성 보장
- 📊 문서 메타데이터 관리

## 🔧 기능

### 1️⃣ 문서 품질 검사
```
✓ 문서 존재 확인
✓ 파일 크기 검증
✓ 문서 형식 검사
✓ 인코딩 확인
✓ 파일 권한 검증
```

### 2️⃣ 일관성 검증
```
✓ 내부 링크 검증
✓ 참조 일관성 확인
✓ 용어 통일 확인
✓ 구조 일관성 검사
✓ 메타데이터 일관성
```

### 3️⃣ 내용 분석
```
✓ 제목 구조 검증
✓ 목차 자동 생성/검증
✓ 섹션 균형 분석
✓ 코드 블록 검증
✓ 이미지 참조 확인
```

### 4️⃣ 최적화 제안
```
✓ 가독성 개선 제안
✓ 구조 개선 제안
✓ 콘텐츠 누락 감지
✓ 중복 콘텐츠 감지
✓ 스타일 정규화 제안
```

## 🎓 핵심 기능

### 문서 스캔
```javascript
scanDocuments() {
  1. 모든 .md 파일 검색
  2. 파일 메타데이터 수집
  3. 문서 구조 분석
  4. 콘텐츠 인덱싱
}
```

### 품질 검사
```javascript
qualityCheck() {
  1. 파일 크기 검증
  2. 형식 검증
  3. 인코딩 확인
  4. 구조 검증
  5. 링크 검증
}
```

### 일관성 검증
```javascript
consistencyCheck() {
  1. 용어 통일 확인
  2. 구조 일관성 검사
  3. 참조 유효성 검증
  4. 메타데이터 일관성
}
```

### 리포트 생성
```javascript
generateReport() {
  1. 검사 결과 수집
  2. 점수 계산
  3. 개선 사항 정렬
  4. 리포트 생성
  5. 출력
}
```
