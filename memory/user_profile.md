**관심사**: 자동화, 체계적 프로젝트 관리, Claude Agent 활용

## 기술 수준

- HTML/CSS/JavaScript: 중상 (직접 요청 및 코드 리뷰 가능)
- 시스템 설계: 상 (하네스 아키텍처 이해)
- GitHub: 중상 (Issue 기반 협업 선호)

## 협업 스타일

**선호 방식**:
1. Issue 등록 후 "skill로 해결해줄래?"로 요청
2. 명확한 요구사항 전달 (CLAUDE.md에 문서화함)
3. 빠른 피드백 및 검증

**싫어하는 것**:

- 라이브러리 추가 (soul.md 철학 위배)
